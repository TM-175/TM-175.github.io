InkTex

A local desktop LaTeX editor that keeps source, compiler feedback, and PDF preview together.

A shorter editing loop

I built InkTex for the way I write technical documents. The source sits beside the rendered PDF, and the app compiles the document with a TeX engine installed on my machine.

Making compiler output useful

InkTex turns compiler messages into structured diagnostics that link back to the source line. Multiple TeX engines and cross-platform packaging keep the workflow useful across different desktop setups.

Built with

Rust, TypeScript, Tauri, Monaco, PDF.js
